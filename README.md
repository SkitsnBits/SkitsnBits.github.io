# SkitsnBits.github.io
This git hub is here to update the poster in the Skits 'n Bits world.  For this to properly show up in the world, the name of the image has to match this EXACTLY

SkitsnBits Current Promotional Poster.png

To update the poster follow these steps:
1) Rename the poster you intend to replace by adding "PREVIOUS-[year]-[month]-[date] - [Name of the event the poster was promoting].png".  e.g. PREVIOUS-2026-12-31 - Dawn of the final day.png
    * To do this, go to the image folder, click on the filename of the current poster.  In the top righthand side of the window, you'll see an edit button. Click that shit.
    * In the "Breadcrumb" area in the top left of the main window, you'll see the path SkitnBits.github.io/image/[name of current poster].  That is an editable field, so you can edit the name of the old poster there.
    * Click [Commit changes...] in the top right of the screen.
2) Click on the [Add file] button in the top right of the screen.  Upload the new poster and make sure it is named EXACTLY: SkitsnBits Current Promotional Poster.png
    * This is optional, but consider putting the date and name of the event that the poster is advertising in the [Add an optional extended description...] area. 
3) Pat yourself on the back.  You're done!
